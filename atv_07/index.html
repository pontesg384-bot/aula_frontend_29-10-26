Bem-vindo à minha página!

Esta página foi desenvolvida utilizando HTML e CSS. O HTML organiza os elementos e o CSS modifica a aparência visual do site.

O que é HTML?

HTML é uma linguagem de marcação utilizada para criar a estrutura das páginas da internet.

O que é CSS?

CSS é utilizado para estilizar páginas, adicionando cores, fontes, tamanhos e espaçamentos.
