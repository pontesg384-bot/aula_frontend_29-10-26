# Atividades de Front-End – HTML e CSS

Repositório destinado às atividades práticas da disciplina de Desenvolvimento Front-End para Web, desenvolvidas durante as aulas.

## 📚 Atividades

### 🔹 Aula 07 – Conceitos DIV e Introdução CSS

Desenvolvimento de uma página web utilizando HTML e CSS, trabalhando a organização dos elementos através de DIVs.

**Conceitos utilizados:**
- Estrutura HTML;
- Elementos DIV;
- Classes CSS;
- Cores de fundo (`background-color`);
- Margens (`margin`);
- Espaçamentos internos (`padding`);
- Largura (`width`);
- Organização dos elementos com Flexbox.

**Estrutura da página:**
- Cabeçalho;
- Menu lateral;
- Conteúdo principal;
- Rodapé.

**Pasta:** `atividade-aula07`

### 🔹 Aula 08 – Estilização de Textos com CSS

Desenvolvimento de uma página sobre Tecnologia e Desenvolvimento Web, aplicando diferentes propriedades CSS para personalizar os textos.

**Conceitos utilizados:**
- `font-family`;
- `color`;
- `font-size`;
- `font-style`;
- `font-weight`;
- `text-indent`;
- `text-align`;
- `text-decoration`;
- `letter-spacing`;
- `word-spacing`;
- `line-height`;
- `text-transform`.

**Pasta:** `atividade-aula08`

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Entre na pasta da atividade desejada.
4. Abra o arquivo `index.html` no navegador.
